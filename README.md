# 100 Days of Code: The Complete Python Pro Bootcamp

My solutions to the projects in Dr. Angela Yu's
[100 Days of Code](https://www.udemy.com/course/100-days-of-code/) Python course.
Each project lives in its own file, with a short description at the top of the
file explaining the task.

## Projects

| Day | Project | File | Concepts |
|-----|---------|------|----------|
| 1 | Band Name Generator | [day_01_band_name_generator.py](day_01_band_name_generator.py) | input, print, variables |
| 2 | Tip Calculator | [day_02_tip_calculator.py](day_02_tip_calculator.py) | data types, math operators, f-strings |
| 3 | Escape the Alien Spaceship (text adventure) | [day_03_escape_the_alien_spaceship.py](day_03_escape_the_alien_spaceship.py) | if / elif / else, nested conditions |
| 4 | Rock, Paper, Scissors | [day_04_rock_paper_scissors.py](day_04_rock_paper_scissors.py) | random, functions, input validation |

More projects will be added as I progress through the course.

## Running a project

Requires Python 3.8+.

```bash
python day_01_band_name_generator.py
```
